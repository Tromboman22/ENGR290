# ENGR290
ENGR 290 technical assignments and hovercraft code

## Opening the Project

To open this project in VS Code, use one of the following methods:

1. **Open the workspace file** (recommended): Open `ENGR290.code-workspace` in VS Code
2. **Open the folder**: Open the repository folder directly in VS Code

The workspace file provides proper configuration for Arduino/C++ development with IntelliSense support.
